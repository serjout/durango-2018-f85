    Power circuits for the front blower, BSM radars and rear camera: 2018 Dodge Durango R/T 5.7L AWD (VIN 1C4SDJCT3JCXXXXXX), and whether they share F85's relay¶

    Локальные копии документов

    Пути вида docs/sources/... указывают на копии документов в приватном репозитории, на сайте их нет. Пользуйтесь ссылками на оригинальные страницы или указателем источников.

    Primary source: the LEMON manual for the 2018 Durango Citadel 5.7L VIN T AWD. That site states the manual is identical to the "Durango R/T, AWD" manual except for labor times, fluids and tire fitment (vehicle page). Wiring diagrams on lemon-manuals are vector SVG files. I read them by rendering them to PNG and by extracting their text labels. Pin, circuit and colour data below come from the diagrams and from the factory connector end-view tables. Labels: - VERIFIED: read directly in a 2018 Durango document at the URL given. - STRONG INFERENCE: deduced from verified documents. - UNVERIFIED: not confirmed.

    Question 1: Front blower power path. Which relay drives the motor, what feeds it, what energises the coil, and what roles do the power module and F99 play?¶

    Takeaway¶

    The front blower runs through PDC relay K16 "Blower Motor" (connector D876): - Terminal 30 is battery (B+, hot at all times). - Terminal 87 feeds F13 40A, then PDC C7-21 (circuit C7, DB), then the front blower power module. - The coil is energised by no module at all. Coil terminal 85 is fed directly from the output of the RUN 1 relay (K15). Coil terminal 86 is grounded through PDC C7-16 (circuit Z919) to G919A.

    Blower speed is controlled separately: the A/C heater module (ATC) sends a PWM signal on C56 to power module C1-3. F99 is the A/C heater module's RUN/START ignition feed, not part of the motor's power path. K16 therefore closes whenever K15 RUN 1 is energised.

    Cited Findings¶

    • VERIFIED. PDC relay designations: K16 = D876 "Blower Motor", K15 = D842A "Run 1", K12 = D842B "Run 2", K08 = D893 "Run / Start", K13 = D816 "Blower Motor - Rear", K06/K14 = Run/Accessory 1/2. Source: the PDC table image ("Dodge Durango (WD)", Underhood PDC). Run 1 relay location page — image GCWD1243624; PDC layout
    • VERIFIED (layout image). K12, K13, K14, K15 and K16 sit side by side in the front row of the PDC's lower relay field, at the "Front" edge. PDC layout page
    • VERIFIED. K16 Blower Motor Relay wiring:
    • 30 = "HOT AT ALL TIMES".
    • 87 → FUSE 13 40A → PDC C7 pin 21, DK BLU.
    • 86 → PDC C7 pin 16, BLK → S2505 → G919A. The diagram's location note for G919A is "behind front of right quarterpanel".
    • 85 ← a wire inside the PDC from the RUN 1 RELAY's 87 output.
    • Source: Automatic A/C Circuit 1/4, page, SVG VA585297
    • VERIFIED, cross-check from a second diagram. In Power Distribution Circuit 1/4, Blower Motor Relay terminal 85 ties into the RUN 1 relay output bus at the F98 node. That bus also feeds F95, F96, F97, F98 and the RUN 2 relay coil (85). Power Distribution page, SVG VA586498
    • VERIFIED. End view of K16 (D876): "Relay_Micro", harness family PDC_Underhood, pin 86 = Z919 internal GROUND. Relay-Blower Motor D876
    • VERIFIED. PDC C7 pinout (PDC C7 end view):
    • pin 21 = C7, DB, 4.0 mm², "BLOWER MOTOR SUPPLY"
    • pins 4, 16, 39 = Z919, BK, "GROUND"
    • pin 12 = K619, BN/OG, "IGNITION RUN CONTROL OUTPUT"
    • pin 13 = F923, PK/YE, "RUN RELAY CONTROL"
    • VERIFIED. Front blower path downstream of the PDC:
    • DK BLU circuit C7 → XY5020A pin 29 → front blower power module C1 pin 6 "BLOWER MTR SPLY".
    • Module C1-5 GND → BLK Z911 → G911A ("under front of center console").
    • Module C1-3 "BLOWER CTRL" ← DK BLU/BLU C56, from A/C heater module C1 pin 15.
    • Module C2-1 → DK BLU/WHT (C7) → blower motor pin 1 "BLOWER MTR SPLY".
    • Module C2-2 ↔ DK BLU/BRN Z134 ↔ blower motor pin 2 "BLOWER MTR CTRL". This pair is shielded, with an NCA drain (S000).
    • Source: Automatic A/C Circuit 2/4, SVG VA585298, on the A/C diagrams page
    • VERIFIED. End view of blower power module C1: 3 = C56 DB/BU "BLOWER CONTROL"; 5 = Z911 BK 4.0 "GROUND"; 6 = C7 DB 4.0 "BLOWER MOTOR SUPPLY". Module-Power-Blower Motor-Front C1
    • VERIFIED. The blower power module runs on PWM. The A/C-heater control's PWM signal goes to a comparator that compares it with blower motor feedback, and the module outputs a linear voltage that sets the speed. The module is diagnosed with a scan tool. Blower motor power module operation
    • VERIFIED. A/C heater module power and bus (VA585297):
    • C1-2 "FSD B(+)": RED A937 ← F49 10A (hot at all times) via PDC C5-25 / S2426.
    • C1-1 "FUSED IGN RUN/START CTRL OUTPUT": PNK/GRN F948, via S2449 / XY5020A-15 / S2448 ← PDC C6-36 ← F99 10A. Per Power Distribution 3/4 (VA586500) and Automatic A/C 3/4 (VA585299), F99 is "HOT W/ RUN/START RELAY ENERGIZED".
    • C1-6 ground: BLK Z912 → G912A.
    • C1-4 / C1-5: CAN IHS (+/−), circuits D101 / D102.
    • VERIFIED. PDC C6 pin 36 = F948, PK/GN, "FUSED IGNITION RUN/START CONTROL OUTPUT" (F99 output). PDC C6 end view
    • VERIFIED. Factory fuse table:
    • F13 40A "Blower Motor Front"
    • F49 10A "Integrated Central Stack/Climate Control"
    • F99 10A "Climate Control/Driver Assistance Systems Module/DSRC"
    • F37 25A "Rear Blower Motor"
    • F103 10A "Cabin Heater (Diesel)/Rear HVAC"
    • Sources: Fuse - Relay Locations And Types. The owner's manual has the same entries (2018 Durango OM PDF).
    • VERIFIED. The rear blower (for comparison) is a separate chain:
    • K13 Rear Blower Motor Relay: 30 = B+; 87 → F37 25A → PDC C7-3 (BLU/BRN C51) → rear blower power module pin 3.
    • K13 coil 85 ← PDC C7-8 ← external loop from C6-28 ← F103, which is on RUN 2.
    • K13 coil 86 → PDC C7-4 → G919A.
    • Source: VA585297, VA586498

    Inferences¶

    • STRONG INFERENCE. The front blower motor needs all of the following:
    • (a) K15 RUN 1 energised and its 87 output live (this energises the K16 coil);
    • (b) K16 contacts and F13;
    • (c) circuit C7 continuous through PDC C7-21 and XY5020A-29 to module C1-6;
    • (d) G911A ground at module C1-5;
    • (e) a PWM command from the A/C heater module on C56, which in turn needs F49 + F99 + CAN;
    • (f) a healthy module and motor.

    The climate UI works and the speed bars change, which points to (e) being alive. A dead K15 output, a dead K16, or a break in the F13/C7 path would each leave the motor still. - STRONG INFERENCE. No module switches K16. It follows RUN 1. Checking 12 V at power module C1-6 (DB, circuit C7) with ignition RUN would show directly whether the power side is alive, which separates PDC-side faults from module/motor faults. - STRONG INFERENCE. K16, K15, K12 and K13 are all "Relay_Micro" parts. Their end-view pages share the same pin-face image (GCWD1006402), and their titles lack the "(On PCB)" tag given to the soldered relays (A/C clutch, fuel pump, horn, wipers). That suggests they are plug-in micro relays. There is a conflict, however: the PDC description says the PDC "houses the maxi-type cartridge fuses and solid state relays" (PDC description). Whether they are removable has to be confirmed visually.

    Gaps¶

    • The wiring diagram does not state the internal resistance of the K16/K15 coils or the K16 contact rating.
    • No 2018 Durango blower-specific TSB was found (see Q4).
    • The diagram's location text "G919A (behind front of right quarterpanel)" for a ground of the engine-compartment PDC relays could not be checked against a photo; location image GCWD1242919 was not reviewed.

    Question 2: BSM power. Fuse, relay and grounds for the left and right rear radar sensors, which CAN bus they use, and the master/slave arrangement¶

    Takeaway¶

    Both blind-spot radars (LBSS and RBSS) share the same supply chain: - Source: F95 10A, "HOT W/ RUN 1 RELAY ENERGIZED" (K15). - Path: PDC C7-13 → circuit F923 PK/YE "RUN RELAY CONTROL" → splice S2442 (right front door sill, "W/ BLIND SPOT") → XY4000A-12 → I701-J → S04A (rear fascia harness) → pin 5 of each sensor. - Ground: circuit Z917 → S03A → I701-E → G917A (left front of cargo area). - Bus: both sit on CAN-IHS. The LBSS is the master and the RBSS the slave. The LBSS talks to the BCM (the CAN gateway), which relays to the cluster on CAN-C.

    Cited Findings¶

    • VERIFIED. BSM circuit (Navigation Fig 1, VA584193 on the Navigation diagrams page):
    • Power: "HOT W/ RUN 1 RELAY ENERGIZED" FUSE 95 10A → C7-13 PNK/YEL → S2442 → XY4000A-12 → I701-J → S04A → LBSS pin 5 and RBSS pin 5, labelled "RUN RLY CTRL".
    • LBSS: pin 6 DK BLU/WHT CAN IHS(+); pin 7 WHT CAN IHS(−); pin 8 BLK GND.
    • RBSS: pins 8 and 3 BLK GND; pin 6 DK GRN/WHT CAN IHS(+); pin 7 WHT CAN IHS(−).
    • Grounds: → S03A → I701-E → G917A "(left front of cargo area)".
    • Mirror indicators: driven by the door modules (DDM C1-3 / C1-2, PDM C1-3 / C1-2).
    • VERIFIED. LBSS end view (harness Fascia_Rear): 5 = F923 PK/YE "RUN RELAY CONTROL"; 6 = D215 DB/WH CAN IHS(+); 7 = D216 WH CAN IHS(−); 8 = Z917 BK GROUND. Sensor-Blind Spot-Left D2481A
    • VERIFIED. RBSS end view: 3 = Z917 BK GND; 5 = F923 PK/YE; 6 = D217 DG/WH CAN IHS(+); 7 = D218 WH CAN IHS(−); 8 = Z917 BK GND. Sensor-Blind Spot-Right Rear D2480A
    • VERIFIED. Splice S2442 (Body harness) carries circuit F923 PK/YE 0.35 "RUN RELAY CONTROL". S2442 end view. G917A is circuit Z917 in the Under_Body harness (G917A).
    • VERIFIED. Bus roles: "The LBSS is a master node, while the RBSS is a slave node. The two nodes communicate with each other over the … CAN-IHS data bus." The LBSS reports to the BCM, and "the BCM, which is a CAN-C gateway, relays the message to the IC over the CAN-C data bus". The LBSS also messages the DDM/PDM (mirror icons) and the radio (chimes). Sensor, Blind Spot: Operation; BSM System Description
    • VERIFIED. The cluster message "SERVICE BLIND SPOT SYSTEM" means the BSM system is unavailable due to a monitored system fault. "TEMPORARILY UNAVAILABLE" means blockage or misalignment. D&T - Blind Spot Monitor System
    • VERIFIED. The LBSS DTC list includes B2199-16 (battery voltage below threshold), U0011-00 (CAN interior bus off), U0140-00 (lost communication with BCM), U0203/U0204 (lost communication with left/right door module) and U11FA-00 (lost communication with right blind spot sensor). LBSS Electrical Diagnostics
    • VERIFIED. Power Distribution 1/4 confirms F95 → C7-13 → S2442 "(right front door sill)(w/ blind spot)", and that F95 hangs off the RUN 1 relay's 87 bus. VA586498

    Inferences¶

    • STRONG INFERENCE. If both sensors lose F923, the master LBSS is silent on CAN-IHS. The BCM/cluster would then show the BSM fault ("SERVICE BLIND SPOT SYSTEM" or similar), and other modules would log lost-communication codes with the LBSS. No sensor DTCs can be read while the sensors are unpowered.
    • STRONG INFERENCE. Both sensors share one supply (F95 → C7-13 → S2442 → XY4000A → I701 → S04A) and one ground chain (S03A → I701-E → G917A). A simultaneous failure of both points upstream of S04A, or to a shared ground, rather than to the two sensors themselves.

    Gaps¶

    • I did not find the exact cluster text this vehicle shows, nor a CAN-IHS U-code for the BCM losing the LBSS (the BCM DTC lists were not opened).
    • The sensors' current draw and whether they sleep on CAN were not found.

    Question 3: Rear camera. Power source, video receiver, and what causes the blue screen¶

    Takeaway¶

    The rear camera has no fuse of its own: - Power: circuit F923 from the same F95 / C7-13 / S2442 feed as the BSM ("RUN RLY CTRL"), then XY2120A-6 → I6742A-1 → camera. - Ground: Z923 → G923A (base of left D-pillar). - Wake-up: the BCM sends the imager wake-up over LIN (CBC 3, circuit D403, BCM C5-45) in reverse. - Video: analog NTSC on X970 / X971 / X972 (signal / return / shield) to radio C1 pins 31 / 32 / 33.

    It does not go through the ParkSense module. The radio switching to the camera view proves that the reverse message is getting through. An empty or blue screen means no video arrives, and loss of the F923 run-relay feed is the first item in the factory list of possible causes.

    Cited Findings¶

    • VERIFIED. Rear View Camera circuit (Navigation Fig 8, VA584199, Navigation diagrams page):
    • Power: "HOT W/ RUN 1 RELAY ENERGIZED" FUSE 95 10A → C7-13 PNK/YEL → S2442 "(W/ BLIND SPOT)" → XY2120A-6 → I6742A-1 → RED F923 → camera "RUN RLY CTRL".
    • Ground: camera GND BLK Z923 → I6742A-6 → XY2110A-14 → G923A ("base of left D pillar").
    • LIN: camera LIN BUS CBC 3 BLU D403 → I6742A-5 → XY2120A-10 → S2433 (right front door sill) → BCM C5-45 (ORG/DK BLU D403).
    • Video: CAMERA SIG X970 / RTN X971 / SHLD X972 → I6742A → XY2110A → XY5010A → Radio C1 pins 31 (SIG), 32 (RTN), 33 (SHLD).
    • VERIFIED. Radio side: premium radio C1-31 X970 "CAMERA SIG", C1-32 X971 "CAMERA RTN", C1-33 X972 "CAMERA SHIELD" (Radio diagrams; e.g. VA584344).
    • VERIFIED, with a conflict. The camera end view (harness Rear_Camera_Jumper, D6742A) lists 1 = F923 RD "RUN RELAY CONTROL", 2 = X970 GN, 3 = X971 WH, 4 = X972 shield, 5 = D403 BL LIN, 6 = Z923 BK GND (Camera-Rear end view). The wiring diagram VA584199 instead numbers the camera pins 1 = GND, 2 = LIN, 3 = RUN RLY CTRL, 4 = SHLD, 5 = RTN, 6 = SIG. Circuit codes and colours agree between the two; pin numbers at the camera are UNVERIFIED. Identify wires by circuit/colour, not by pin number.
    • VERIFIED. "The Rear View Camera (RVC) receives power from a run relay control output circuit located in the Power Distribution Center (PDC)… When the transmission is shifted into the Reverse position, the BCM sends a signal over the LIN bus to the RVC that excites the imager." Video is NTSC-M composite. The shield is grounded only at the radio. Camera, Rear: Operation
    • VERIFIED. "Rear Camera Inoperative With RRM Display":
    • Theory: "The fused ignition circuit supplies power to the camera… in reverse, the rear camera has priority."
    • Set condition: "No rear picture is displayed on Radio with the vehicle in reverse."
    • Possible causes (in order): FUSED RUN RELAY OUTPUT CIRCUIT, GROUND CIRCUIT, CAMERA SIGNAL, RETURN, SHIELD, camera.
    • Step 2: with the camera unplugged and ignition ON, measure F923 to ground for battery voltage. Step 3: Z923 ground below 5 Ω.
    • Sources: Theory, Possible Causes, Diagnostic Test
    • VERIFIED. The general rear-camera D&T table separates two cases. "No camera image… and no backup lamps" points to BCM inputs and outputs and the reverse input. "No camera image… backup lamps do operate" points to the camera ground, feed, shield, return and signal, or the camera itself. D&T - Rear Camera
    • VERIFIED, with a discrepancy. The fuse table and owner's manual label F95 "Rear Camera/ParkSense" (fuse spec; owner's manual). In the wiring diagram, however, the Park Assist Module is fed from F99 ("HOT W/ RUN/START RELAY ENERGIZED", C6-36 → S2448 → PAM C1-1), with ground C1-7 → G924A and CAN-C on C1-6 / C1-12 (Parking Assistant Circuit VA584200; Power Distribution 3/4 VA586500).

    Inferences¶

    • STRONG INFERENCE. The radio clearly receives the reverse status: it switches to the camera page. So the CAN reverse message and the radio's video input mode are working. The empty screen is consistent with no NTSC signal from the camera. The most likely cause is the missing F923 feed, because the BSM shares the same feed and is also dead.
    • UNVERIFIED. The service information does not say what colour the Uconnect screen shows when there is no video sync. The "blue screen" interpretation comes from general experience, not from the manual.
    • STRONG INFERENCE. If ParkSense (F99, RUN/START) still works while the camera does not, that supports a fault on the RUN 1 / F95 side rather than in RUN/START.

    Gaps¶

    • Camera current draw and the LIN message content are not documented.
    • The camera connector pin-number conflict (end view vs diagram) is unresolved.
    • I found no 2018 Durango TSB on a camera with no image apart from the radio-software "Radio and Back-up Camera Enhancements" bulletins 08-084-19 and 08-017-21 (titles only, from the carcomplaints list; not opened).

    Question 4: Do the BSM, camera or blower share a relay or fuse with F85? Concrete list of fuses and circuits¶

    Takeaway¶

    Yes. All three failed systems and F85 hang off the RUN 1 relay (K15): - BSM and camera: F95, which is on RUN 1's 87 bus. - Front blower: K16's coil, which is fed from RUN 1's 87 bus. - F85 (ORC): on the RUN 2 relay (K12) output, and the K12 coil is itself powered from RUN 1's 87 bus.

    So one loss of K15's output kills all four symptoms at once. F86, the other ORC fuse, and F99 (HVAC/ParkSense) are on the separate RUN/START relay (K08), which matches F86 being normal and the engine and HVAC UI working.

    The one item that does not fit is the reported "F95 normal" reading. If F95 really has 12 V under load with ignition RUN, K15 is working. In that case the four symptoms would need at least two separate faults: (a) C7-13/F923/S2442 for BSM + camera, and (b) the K12 RUN 2 relay for F85, plus a separate blower fault. F95 should be re-measured.

    Cited Findings¶

    • VERIFIED. Power Distribution 1/4 (VA586498, page). I checked the crops at high resolution.
    • RUN 1 relay (K15): 30 = PDC internal B+ bus; 85 = PDC C7-12 BRN/ORG → BCM C5-36; 86 = internal ground bus → PDC C1-12 BLK → S2547 → G909A (right rear of engine compartment). Its 87 output bus feeds:
      • F95 10A → C7-13
      • F96 10A → C7-15
      • F98 20A → C7-19
      • F97 20A → C7-17
      • the Blower Motor Relay (K16) coil 85
      • the RUN 2 relay (K12) coil 85
    • RUN 2 relay (K12): 30 = B+; 85 ← RUN 1 output; 86 → the same ground bus. Its 87 output is a separate bus feeding:
      • F40 10A → C1-10
      • F103 10A → C6-28
      • F85 10A → C6-15
      • F101 15A → C6-32
      • F100 10A → C6-34
    • The RUN 1 bus ends at the F97 / RUN 2 coil node. It is not connected to the RUN 2 output bus.
    • VERIFIED. The SRS diagram confirms:
    • "HOT W/ RUN 2 RELAY ENERGIZED" FUSE 85 10A → PDC C6-15 PNK/YEL F929 → ORC C2-104 "FUSED IGN SW OUTPUT (RUN)".
    • "HOT W/ RUN/START RELAY ENERGIZED" FUSE 86 10A → PDC C6-13 PNK/GRN F945 → ORC C2-103 "IGN RUN/START CONTROL OUTPUT".
    • ORC ground C2-101 BLK Z913 → G913A; ORC on CAN-C (C2-54 / C2-53).
    • Source: Supplemental Restraints 1/3 VA582314 (page)
    • VERIFIED. PDC C6 end view: 15 = F929 PK/YE "FUSED IGNITION SWITCH OUTPUT (RUN)"; 13 = F945 PK/GN "IGNITION RUN/START CONTROL OUTPUT"; 10 = K617 BN "RUN/START RELAY CONTROL"; 28 = F931; 32 = F925; 34 = F938; 36 = F948. PDC C6
    • VERIFIED. Relay end views:
    • K15 Run 1 (D842A): 85 = K619 "IGNITION RUN CONTROL OUTPUT", 86 = Z909 GROUND. Run 1
    • K12 Run 2 (D842B): 86 = Z909 GROUND. Run 2
    • K08 Run/Start (D893): 30 = A0 B(+), 85 = Z909 GROUND, 86 = K617 control. Run/Start

    • VERIFIED. Loads on this bus include the ORC (F86 → C2-103), park assist, A/C heater module, FFCM, rear A/C control, ACC, PCM, EPS, ABS, SGW and cluster.

    • F97 → SF922A → heated seats module C3-6 / C4-2
    • F40 → S2526 → right front lamp assembly and headlamp leveling motors (premium)
    • F101 → XY5020A-7 → S2443 → in-car temperature sensor pin 3 and humidity sensor pin 3
    • F100 → SP2589 → active damping module C2-14 / C2-47
    • F103 → rear blower relay (K13) coil
    • VERIFIED. FCA GPOP tech tip 9003816 (11/01/2017, MY18 WD), PDC part numbers 68320920A / 68320923A: "For 2018 WD, prior to replacing the Power Distribution Center (PDC), you MUST contact the STAR Center … for diagnostic assistance and pre-authorization." It contains no symptom description. NHTSA PDF MC-10216108-9999; carcomplaints listing

    Inferences¶

    • STRONG INFERENCE. All four failures (BSM, SRS warning, front blower, camera) are explained by one point: no output from RUN 1 relay K15. Candidate causes:
    • the relay itself;
    • its BCM drive, K619 BRN/ORG from BCM C5-36 to PDC C7-12;
    • its coil ground Z909 → PDC C1-12 → G909A, which is shared with K08/K12 (and since K08 works, that ground is probably fine);
    • its B+ feed;
    • the PDC-internal 87 bus.

    With K15 off: F95 is dead (BSM + camera), K16 is not energised (front blower), and K12 is not energised, so F85 is dead (ORC C2-104 loses its RUN input and the SRS lamp comes on). F86 and F99 survive on K08. - STRONG INFERENCE. If K15 is the cause, these should also be dead (check them to confirm): - F96 (rear heated-seat switches) - F97 (rear heated seats, heated steering wheel) - F98 (front heated/ventilated seats) - F40 (DRL / headlamp leveling) - F101 (auto-dim mirror / smart high beams, plus the ATC humidity and in-car temperature sensors) - F103 (rear blower relay coil → rear blower) - F100 (active damping, if equipped)

    These should still work because they are on Run/Start or Run/Acc: engine, ParkSense (F99), ABS/EPS, cluster, windows (Run/Acc 1 F66 / CB1), power outlets. - STRONG INFERENCE. How to read F95 and the other fuses: - F95 live but F85 dead, with K15 good: K12 RUN 2 (or its output) is failing, but RUN 2 cannot explain the BSM, camera or front blower. Those would need F923/S2442 (BSM + camera) and K16/F13/C7 (blower) faults as well. - F96/F97/F98 also dead: K15 is the culprit, and the F95 reading should be re-checked with a test light (loaded) on both fuse test points, ignition RUN. - Direct check: about 12 V on K15's coil control (PDC C7-12, BN/OG, from BCM C5-36) in RUN, and on the K15 87 bus. - STRONG INFERENCE (practical, needs confirmation that the relays plug in). K12–K16 are the same "Relay_Micro" type in one row. If they are removable, a known-good relay from a less critical position, e.g. K13 Rear Blower, could be swapped into K15 as a test. The PDC description's "solid state relays" wording conflicts with this; inspect visually first. - Shared splice: S2442 (right front door sill) and connector C7-13 are common only to the BSM and the camera, not to the blower or F85. A fault there could explain only the BSM + camera pair.
