    Factory power-distribution path for PDC fuses F85 / F86 — 2018 Dodge Durango R/T 5.7L AWD (VIN 1C4SDJCT3JCXXXXXX)¶

    Локальные копии документов

    Q1. Which relay feeds F85, and which feeds F86?¶

    Takeaway¶

    F85 is fed by the RUN 2 relay (K12), not by RUN 1 or RUN/START. F86 is fed by the RUN/START relay (K08). So F85 and F86 sit on two different relay buses inside the PDC. This fits the measurement: F85 = 0 V while F86 is normal.

    Cited Findings¶

    • VERIFIED: in PD-1, the RUN 2 RELAY 87 output feeds one internal bus carrying F40 10A, F103 10A, F85 10A, F101 15A and F100 10A. — PD-1 SVG
    • VERIFIED: the A/C diagram labels F103 and F101 "HOT W/ RUN 2 RELAY ENERGIZED". This independently confirms that this bus is the RUN 2 bus. — AC-1 SVG
    • VERIFIED: in PD-3, the RUN/START RELAY 87 output feeds a bus carrying F77 10A, F86 10A, F99 10A, F75 10A, F78 10A, F76 10A and F88 15A. — PD-3 SVG
    • VERIFIED: F85 output leaves at PDC C6 pin 15, circuit F929, PK/YE 0.50, "FUSED IGNITION SWITCH OUTPUT (RUN)". — PDC C6 end view (D6630F)
    • VERIFIED: F85 runs to ORC C2 pin 104. The diagram shows PNK/YEL directly from PDC pin 15 to ORC C2-104, with no splice drawn. — PD-1 SVG
    • VERIFIED: the ORC C2 connector table gives pin 104 as F929 PK/YE 0.50 "FUSED IGNITION SWITCH OUTPUT (RUN)". — ORC C2 end view (D3834B)
    • VERIFIED: F86 output leaves at PDC C6 pin 13, circuit F945, PK/GN 0.50, "IGNITION RUN/START CONTROL OUTPUT" and runs to ORC C2 pin 103 (F945 PK/GN). — PDC C6; ORC C2; PD-3 SVG
    • VERIFIED: ORC DTC B212D-13 "Ignition Run Only Input – Circuit Open" lists these possible causes:
    • "(F929) RUN RELAY CIRCUIT OPEN"
    • "POWER DISTRIBUTION CENTER FUSE F85 OPEN"
    • "(F929) FUSED RUN RELAY OUTPUT CIRCUIT OPEN OR SHORTED TO GROUND"
    • the ORC itself

    — B212D-13 Possible Causes - VERIFIED: B212D-13 sets when the ORC sees "less than 6 volts on the ignition voltage supply circuit for more than 15 seconds while the battery circuit maintains system operating voltage". — B212D-13 Set Condition - VERIFIED: the service manual fuse chart and the 2018 owner's manual (PDF pages ~383–384) both list F85 10A Red "Airbag Module" and F86 10A Red "Airbag Module". — Fuse–Relay Locations and Types; 2018 Durango Owner's Manual 8598.pdf

    Inferences¶

    • The ORC has two separate ignition inputs:
    • "Run only" on F929 / F85 / RUN 2 (K12), which gives B212D-xx.
    • "Run/Start" on F945 / F86 / RUN/START (K08), which gives B212C-xx.

    With F85 at 0 V, the ORC should log B212D-13 or B212D-16 and light the airbag lamp, while B212C stays clear. - The other ORC inputs (battery feed, ground Z913 at C2-101) were not part of this task.

    Gaps¶

    • The ORC B212D-13 diagnostic test text has copy-paste errors. It calls the fuse "F6" and says the ORC is fed from a "Rear Power Distribution Center". It contradicts the diagram, the C6 table and its own Possible Causes page, which all say F85. Treat F85 as correct. — B212D-13 Diagnostic Test

    Q2. What feeds terminal 30 (B+) of the RUN 2 relay (and of RUN 1 / RUN/START)?¶

    Takeaway¶

    K12 RUN 2 and K15 RUN 1 both take terminal 30 directly from the PDC's internal unfused B+ bus, which is fed by the battery positive cable. K08 RUN/START also takes terminal 30 from that bus, via the internal "B" line. No fuse is drawn between the battery and any of these relays' terminal 30.

    Cited Findings¶

    • VERIFIED: in PD-1, RUN 1 30, RUN 2 30, BLOWER MOTOR RELAY 30, REAR BLOWER MOTOR RELAY 30, F19 and the 3rd-row headrest relay all tie to one bus line in the lower PDC block. That line connects to the upper PDC block's top bus, which also feeds RUN/ACC 1 and RUN/ACC 2 relay 30, F91 and F104. The top bus drops to the RED battery cable at the PDC; the battery (+) and auxiliary battery (start/stop only) are drawn below it. — PD-1 SVG
    • VERIFIED: AC-1 labels this bus at the blower relay / RUN 1 area "HOT AT ALL TIMES". — AC-1 SVG
    • VERIFIED: PD-1 shows the same bus leaving as "A – TO REAR WINDOW DEFOGGER RELAY (DIAGRAM 2 OF 4)". In PD-2 it arrives as "A – FROM REAR BLOWER MOTOR RELAY" and continues unfused to "B – TO RUN/START RELAY (DIAGRAM 3 OF 4)". F25 30A is only a branch off this bus (feeding the wiper on/off relay); it is not in series. In PD-3, "B – FROM FUSE 25" lands on RUN/START relay 30. — PD-2 SVG; PD-3 SVG

    Inferences¶

    • STRONG INFERENCE: the label "FROM FUSE 25" in PD-3 is only a location/anchor label. The drawn connectivity shows the B line branching from the bus before F25, so RUN/START relay 30 is not protected by F25.
    • A failure of the B+ bus itself would kill many always-hot circuits (F19, F91, F104, defogger, horn, door modules and so on). That does not match this vehicle, so terminal 30 of K12 is very likely powered, unless there is a localised open at K12's own terminal or socket.

    Gaps¶

    • The physical form of the main feed (stud / eyelet / bus-bar on the PDC) is not described in the 2018 pages found. The diagram shows only a RED cable joining the bus at the PDC boundary, with no connector cavity.

    Q3. Who controls the relay coils — circuit codes, pins, grounds?¶

    Takeaway¶

    • The BCM high-side drives K15 RUN 1 (85 ← PDC C7-12 ← circuit K619 BN/OG ← BCM C5/E pin 36).
    • K12 RUN 2 has no module control of its own. Its coil terminal 85 is fed internally from the RUN 1 relay's 87 output bus: K12 is a slave of K15.
    • The BCM drives K08 RUN/START via K617 BN (PDC C6-10 ← BCM C1/A pin 18).
    • Coil terminal 86 of RUN 1, RUN 2, RUN/START, RUN/ACC 1 and RUN/ACC 2 all join one common coil-ground line. It leaves at PDC C1 pin 12, Z909 BK, through splice S2547 to ground G909A (right rear of engine compartment).

    Cited Findings¶

    • VERIFIED: in PD-1, RUN 1 relay pin 85 goes to PDC pin 12 (C7), then a BRN/ORG wire, then BCM C5 pin 36. RUN 1 pin 86 goes to the common bottom line. — PD-1 SVG
    • VERIFIED: PDC C7 pin 12 = K619 BN/OG 0.50 "IGNITION RUN CONTROL OUTPUT". — PDC C7 (D6630G)
    • VERIFIED: BCM C5/E pin 36 = K619 BN/OG 0.50 "IGNITION RUN CONTROL OUTPUT". — BCM C5/E (D3806E)
    • VERIFIED: in PD-1, RUN 2 relay pin 85 connects by an internal PDC line to the RUN 1 87 bus, at the junction that also feeds F97 and F98. The junction dot is drawn at F97's input. RUN 2 pin 86 goes to the common bottom (ground) line. — PD-1 SVG (zoom render: docs/sources/power-distribution/renders/s1_run2.png)
    • VERIFIED: in PD-1, RUN/ACC 1 and RUN/ACC 2 relay 86 and the "H" line from the RUN/START relay join one line. It exits at PDC pin 12 (C1), BLK wire, splice S2547, ground G909A "(RIGHT REAR OF ENGINE COMPT)". The bottom line carrying RUN 1 86 and RUN 2 86 is routed up the right edge to the same "H" line. — PD-1 SVG
    • VERIFIED: in PD-3, RUN/START relay pin 86 goes to "H – TO RUN/ACCESSORY 1 RELAY (DIAGRAM 1 OF 4)", which is the common coil ground. RUN/START pin 85 goes to PDC C6 pin 10, BRN wire, BCM C1 pin 18. — PD-3 SVG
    • VERIFIED: PDC C1 pin 12 = Z909 BK 1.0 "GROUND". — PDC C1 (D6630A)
    • VERIFIED: PDC C6 pin 10 = K617 BN 0.50 "RUN/START RELAY CONTROL". BCM C1/A pin 18 = K617 BN 0.50 "RUN/START RELAY CONTROL". — PDC C6; BCM C1/A (D3806A)
    • VERIFIED: RUN/ACC 1 and RUN/ACC 2 coil-85 controls come from BCM C5/E pins 6 (P305 GN/BU) and 9 (P307 GN/GY), both "ACCESSORY DELAY RELAY CONTROL". They enter the PDC at C7-25 and C7-6. — BCM C5/E; PDC C7
    • VERIFIED: BCM DTC B2121-15 "Ignition Run Control 1 – Circuit Short To Battery Or Open", Theory of Operation: "The Body Control Module (BCM) receives the network communication message from the Radio Frequency (RF) Hub indicating run operation is requested. The BCM provides a voltage output through the ignition run relay control circuit, which connects to the coil side of the Ignition Run Relays." — B2121-15 Theory
    • VERIFIED: B2121-15 possible causes are:
    • "IGNITION RUN RELAY CONTROL CIRCUIT OPEN"
    • "…SHORTED TO VOLTAGE"
    • "POWER DISTRIBUTION CENTER (PDC) ASSEMBLY GROUND CIRCUIT OPEN"
    • "RUN RELAY"
    • "POWER DISTRIBUTION CENTER (PDC) ASSEMBLY"
    • "BODY CONTROL MODULE (BCM)"

    The diagnostic test works on the "(K619) Run Relay Control circuit" at BCM C5/E. — B2121-15 Possible Causes; B2121-15 Diagnostic Test

    Inferences¶

    • STRONG INFERENCE: the BCM monitors only K619, the RUN 1 coil drive. There is no BCM output or DTC for RUN 2: its coil is energised only when RUN 1 has closed. So a dead K12 (coil open, contacts, socket) would set no BCM DTC, only ORC B212D-xx and the symptoms of the other RUN 2 loads.
    • STRONG INFERENCE: the RF Hub requests RUN over the network and the BCM executes it. The RF Hub has no direct wire to these coils.
    • Because RUN/START, RUN/ACC 1, RUN/ACC 2 and RUN 1 share the Z909 coil ground with RUN 2, and RUN/START works (F86 OK), the external ground (C1-12 → S2547 → G909A) is intact. A coil-ground open could only be internal, on the branch serving K12 or K15.

    Gaps¶

    • Exact relay-socket cavity numbers in the PDC are not tabulated in the pages found. Only the logical pins 30/85/86/87/87A are shown.

    Q4. Is RUN 2 (and RUN 1 / RUN/START / blower) a plug-in relay or integral to the PDC? Location and part number?¶

    Takeaway¶

    • The 2018 Durango service procedure treats the Run relay as removable: "Remove the Run Relay from the PDC… substitute… with a known good relay".
    • The 2018 PDC layout figure shows K12 (Run 2), K15 (Run 1), K16 (Blower Motor), K13 (Blower Motor – Rear) and K14 (Run/Acc 2) as individual black relay blocks in the bottom row of the underhood PDC, with K08 (Run/Start) in the centre column. These are relay positions visible from the top of the PDC.
    • The PDC itself is serviced only as an assembly, as part of the engine-compartment body harness.
    • The exact Mopar part number of the K12 relay is UNVERIFIED.

    Cited Findings¶

    • VERIFIED: B2121-15 Diagnostic Test, step 2: "Remove the Run Relay from the Power Distribution Center (PDC) Assembly… Temporarily substitute the relay with a known good relay… Replace the Run Relay." Step 3 measures "between ground and the Run Relay terminal in the PDC Assembly". — B2121-15 Diagnostic Test
    • VERIFIED: "The PDC houses the maxi-type cartridge fuses and solid state relays." The PDC is in the left-centre of the engine compartment. — Center, Power Distribution (PDC): Description
    • Conflict: the wiring diagrams place the PDC at the "RIGHT SIDE OF ENGINE COMPT" (PD-1…PD-4) or "RIGHT REAR OF ENGINE COMPT" (AC-1).
    • VERIFIED: "The PDC is serviced as part of the engine compartment body harness." The system description also lists "Standard and Micro-Relays". — Power Distribution: Description
    • VERIFIED: the figure "Underhood Power Distribution Center (PDC) – DODGE DURANGO (WD)" (image G00621551, page revision ID dated 2022-09-16, inside the 2018 manual) gives these relay-table rows, as legible from the low-resolution JPEG:
    Relay Alternate Description
    K08 D893 Run / Start
    K12 D842B Run 2
    K13 D876 (?) Blower Motor – Rear
    K14 D851B Run / Accessory 2
    K15 D842A Run 1
    K16 D874 (?) Blower Motor

    All relay amperages are "N/A". The same figure's fuse table gives F85 alternate F0085U and F86 F0086U. — PDC Layout And Connector Identification; image G00621551 - VERIFIED (same image): positions K1–K16 are drawn as black relay blocks on the top face of the PDC. The bottom (front) row reads, left to right: K12, K13, K14, K15, K16. K5, K6, K9 and K10 stack in the centre column, K8 sits left of centre, and K11 at the lower left. Relays numbered K17–K34 in the table (trailer tow, horn, HID, wiper, 3rd-row headrest, fuel pump, A/C clutch and others) have no visible position in the picture. — image G00621551 - UNVERIFIED (secondary dealer catalogue, not VIN-filtered, no K-position mapping): the 2018 Durango fuse & relay listing shows: - "Relay-Mini Relay" 4692139AA (Engine Compartment) - "Relay-Mini Relay" 4727370AA - "Relay – Micro Power Iso Relay" 68603769AA, which supersedes 68200229AA and 68298547AA (supplier # 871E1ADR1U1512VDC / …1912VDC) - "POWER DISTRIBUTION CENTER Intelligent Power – Includes Fuses, Relays, and Circuit Breakers" 68320920AE → 68425212AB (with Auto Stop-Go), and 68417608AB → 68425216AB; 68425215AB is listed "Without Auto Stop-Go"

    — jeeppartsgiant 2018 Durango relay listing

    Inferences¶

    • STRONG INFERENCE: K12 / K15 / K08 / K16 are plug-in relays. The service procedure removes and substitutes the Run relay, and the layout figure shows them as discrete top-mounted relay bodies.
    • The phrase "solid state relays" in the PDC description may refer to other (internal) relays, such as K17–K34, which have no visible top position. That cannot be confirmed from the text.
    • Which physical style K12 uses (mini ISO vs micro ISO) cannot be decided from the 2018 documents found. Swapping K12 with an identical-footprint relay of known function is a practical test, for example K15 RUN 1, or K14 RUN/ACC 2 if it has the same footprint. Footprint identity is not verified.

    Gaps¶

    • No 2018 document found ties a Mopar relay part number to cavity K12.
    • The Mopar store PDC page (https://store.mopar.com/v-2018-dodge-durango--r-t--5-7l-v8-gas/electrical--power-distribution-center-fuse-block-junction-block-relays-and-fuses) returned HTTP 403 to both WebFetch and curl.
    • The relay-table alternates marked "(?)" (D874, D876) are hard to read in the low-resolution JPEG.
    • The PDC location wording conflicts between the description ("left center") and the diagrams ("right side / right rear of engine compt"). Physical left/right should be confirmed on the vehicle.

    Q5. Internal PDC busing — how F85 gets power, and can an internal PDC open give 0 V at F85 while F86 is normal?¶

    Takeaway¶

    Logical path from the factory diagrams:

    Battery (+) cable → PDC internal B+ bus → K12 RUN 2 terminal 30 → (contacts closed only when the K12 coil is energised) → K12 87 → internal RUN 2 bus → F85 → PDC C6-15 (F929 PK/YE) → ORC C2-104.

    The K12 coil is supplied by: BCM C5/E-36 (K619) → PDC C7-12 → K15 RUN 1 coil → K15 87 → internal RUN 1 bus → K12 85. The K12 coil returns through 86 → the common internal coil-ground line → PDC C1-12 (Z909) → S2547 → G909A.

    F86 sits on a completely separate bus (K08 RUN/START 87), so 0 V at both sides of F85 with F86 normal is fully consistent with a fault anywhere in the K12 chain: the K12 relay or its socket terminals, the K12 coil feed from the K15 87 bus, the K12 coil-ground branch, or the internal trace from K12 87 to the F85 cavity.

    Cited Findings¶

    • VERIFIED: the relay and bus topology described in Q1–Q3. — PD-1 SVG; PD-3 SVG
    • VERIFIED: in the B2121 test the factory itself considers an internal PDC open: step 7 is "CHECK THE PDC ASSEMBLY FOR AN INTERNAL OPEN", and if it persists the outcome is "Replace the Power Distribution Center (PDC)". — B2121-15 Diagnostic Test
    • VERIFIED: ORC B212D-13 possible causes include "(F929) RUN RELAY CIRCUIT OPEN", meaning the relay-to-fuse side. — B212D-13 Possible Causes
    • VERIFIED: in PD-1 the RUN 1 87 bus is drawn in this order: F95 → F96 → F98 → (K16 blower relay coil 85 tap) → F97 → (K12 RUN 2 coil 85 tap). — PD-1 SVG

    Inferences¶

    • The diagram is a schematic: the drawn order of taps does not prove the physical bus-bar or trace order inside the PDC.
    • Discriminating tests, all done in RUN with the engine running and readings taken at the fuse test points:
    • (a) Check F40, F101, F103 and F100. These are the other RUN 2 fuses. F101 feeds the in-car temperature and humidity sensors; F103 feeds the rear blower relay coil.
      • If all are 0 V, K12 is not switching. The fault is the K12 relay or socket, or its coil feed/ground.
      • If they are live but F85 is not, there is an internal open between the K12 87 bus and the F85 cavity, or a cavity/terminal fault.
    • (b) Check F97 and F98 (heated seats / heated steering wheel) and F96. These are RUN 1 bus loads drawn on the same side as the K12 and K16 coil taps.
      • If F95 is live but F97/F98 are dead, there is an internal open in the RUN 1 distribution between the F95 tap and the K16/K12 coil taps. That would by itself explain front blower dead + F85 dead.
    • (c) With K12 removed, measure in the K12 socket: the coil-feed cavity should read battery voltage in RUN (from the K15 87 bus); the coil-ground cavity should show continuity to ground; terminal 30 should be hot at all times.
    • Correlation with the reported symptoms (inference):
    • Per the 2018 diagrams, every one of the four failed systems sits downstream of the K15 RUN 1 relay:
      • BSM sensors and rear camera: K15 → F95 → F923.
      • Front blower: K15 87 → K16 Blower Motor relay coil (85); K16 86 → PDC C7-16 (Z919) → G919A; K16 30 = B+; K16 87 → F13 40A → C7-21 "BLOWER MOTOR SUPPLY" (C7 DB).
      • SRS: K15 87 → K12 coil → F85 → ORC.
    • A total K15 output failure would explain all four, but it conflicts with the report that F95 has normal voltage on both sides. Either F95 should be re-measured (with the fuse in, in RUN, against a known-good ground), or the fault is a partial/internal open on the RUN 1 bus downstream of the F95 tap: that explains blower + SRS. The BSM/camera failure would then need a separate cause downstream of F95. For that, note that the BSM sensors and the rear camera share splice S2442 (right front door sill, F923): see Q6.

    Gaps¶

    • No factory document found describes the internal construction of the PDC (bus bars vs printed circuit, solder joints), so "internal open" cannot be localised further from the documentation.
    • No document found gives the actual physical order of taps on the RUN 1 bus inside the PDC.

    Q6. Full consumer lists: the F85 relay (RUN 2) and the F86 / F95 / F99 relays. Does RUN 2 feed BSM, rear camera, blower relay K16 or the HVAC module?¶

    Takeaway¶

    • RUN 2 (K12) feeds only F40, F103, F85, F101 and F100. It does not feed the BSM radars, the rear camera, the front blower relay K16 coil, or the A/C heater (HVAC) control module.
    • BSM + rear camera (F95), the K16 blower relay coil, F96/F97/F98 and the K12 coil itself are all on K15 RUN 1.
    • F86 and F99 are on K08 RUN/START. F99 feeds the A/C heater module, park assist, forward-facing camera, ACC and rear A/C control.
    • F13 (blower power) and F49 (HVAC/ICS) are B+ circuits.

    Cited Findings¶

    K12 RUN 2 bus (VERIFIED, PD-1 SVG + PDC C1 / PDC C6 / PDC C7): - F40 10A → C1-10 F927 PK/YE → S2526 (right side of engine compartment) → right front lamp assembly C2-11; left and right headlamp leveling motors (Premium). - F103 10A → C6-28 F931 PK/YE → loops back into PDC C7-8 (F931) → rear blower motor relay (K13) coil 85. Its 86 → C7-4 (Z919) → G919A, per AC-1. - F85 10A → C6-15 F929 → ORC C2-104. - F101 15A → C6-32 F925 PK/YE → XY5020A-7 → S2443 (right side of dash) → in-car temperature sensor pin 3; humidity sensor via XY7001A-1 (BLK/PNK, pin 3). AC-1 confirms the humidity sensor pin 3 "FSD IGN RUN CTRL OUTPUT" comes from F101. - F100 10A → C6-34 F938 PK/YE → XY6020A → XY8200A → SP2589 → Active Damping Control Module C2-14/C2-47 (if equipped). - The fuse charts label F101 "Electrochromatic Mirror/Smart High Beams" and F103 "Cabin Heater (Diesel)/Rear HVAC", while the wiring diagram shows the loads listed above. — Fuse chart

    Inferences¶

    • Of the four failed systems, only the SRS warning is explained by RUN 2 (K12).
    • The rear camera and BSM are on F95 (RUN 1) through one shared splice S2442 at the right front door sill. If F95 truly has voltage on both sides, a fault at or after S2442 (water/corrosion at the right front door sill area), or at XY2120A / XY4000A, could take out camera + BSM together. This was not verified on the vehicle.
    • The front blower depends on the K15 RUN 1 output (K16 coil), the K16 coil ground at G919A, K16 itself, F13 and the blower power module. It does not depend on RUN 2.
    • HVAC controls responding fits F99 (RUN/START) + F49 (B+) being alive.

    Gaps¶

    • Rear-camera pin conflict: the wiring diagram shows the camera power at camera pin 3 (RED), but the Camera-Rear connector table lists pin 1 = F923 RD "RUN RELAY CONTROL" and pin 3 = X971 "CAMERA RETURN". This was not resolved. — Camera-Rear D6742A
    • The HVAC diagrams AC-2 to AC-4 (blower power module wiring) were downloaded but not analysed in detail. They are outside the F85 scope.

    Q7. Verification of preliminary designations (F929, F945, F923, F948, K15, K12, K08, K16, D842A, D842B, D893)¶

    Takeaway¶

    All of these designations are confirmed by 2018 Durango documents. No adjacent-year substitution was needed.

    Cited Findings¶

    • F929 = F85 output, PDC C6-15 PK/YE, "FUSED IGNITION SWITCH OUTPUT (RUN)" → ORC C2-104 — VERIFIED (PDC C6, ORC C2)

    Q8. VIN / build configuration and document applicability¶

    Takeaway¶

    The VIN decodes cleanly as a 2018 Dodge Durango R/T, AWD, 5.7L V8 gasoline, built in Detroit, MI. The LEMON 2018 "Durango Citadel 5.7L VIN T AWD" manual is stated to be identical to the "Durango R/T, AWD" manual, so the diagrams apply to this vehicle. No VIN-specific PDC variant could be identified.
